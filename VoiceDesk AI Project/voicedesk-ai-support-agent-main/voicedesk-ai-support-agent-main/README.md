# 🤖 VoiceDesk AI – LiveKit + Beyond Presence

This is an AI-powered Support Assistant that combines voice interaction, visual representation, and real-time support tools.
It can see your screen, unblock users, send support ticket emails, and provide both audio and visual cues while performing actions.

## ✨ Key Features

🧠 AI Voice Agent – Built with LiveKit for natural voice interaction
👁️ Screen Sharing – The agent can see your shared screen in real time
📧 Support Ticket Emails – Automatically generate and send support ticket info
🔓 User Management – Unblock or manage users directly from the interface
🎧 Audio Cues – Typing sounds play while the agent performs actions
💡 Visual Cues – On-screen notifications confirm successful operations
🧍 AI Avatar – Realistic visual representation powered by Beyond Presence

## 🧩 Tech Stack

LiveKit (Voice + Realtime Communication)

Beyond Presence (AI Avatar Visualization)

Python (Backend logic)

Email API (Support ticket automation)

Screen Share Integration (User screen visibility)
